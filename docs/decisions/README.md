# Decision records

Short, dated decisions by the maintainer or Planning Desk that are not
architectural ADRs (those live in [`docs/adr/`](../adr/)). Records quote the
decision as made. They do not reopen it. A later decision supersedes an
earlier one only by an explicit new record.
